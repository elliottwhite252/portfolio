A help center built from zero

favorited · Zendesk, GitBook, GitHub Actions, TypeScript

When I joined favorited, a live-streaming startup, it had about ten help articles and no structure behind them. I designed the information architecture, wrote the style guide, and grew the knowledge base to more than 100 articles, working closely with support and engineering on payouts, subscriptions, online safety, and creator onboarding.

To keep the docs maintainable, I treated them like code. I built a GitHub Actions pipeline that publishes to GitBook, a sync from Google Docs to Zendesk for policy pages, and a health-check agent in TypeScript that flags stale or broken articles.

Result: about 3,000 monthly readers, and support tickets dropped by roughly half.

A localization program in 11 languages

favorited · Lokalise, Flutter, ESLint

The app shipped in English only, with strings hard-coded throughout. I set up Lokalise with over-the-air updates in the Flutter app, built a glossary and locale registry, and added an ESLint rule that stops new hard-coded strings from being merged. I also managed translation of policy documents, including Japanese and Simplified Chinese versions of the Community Guidelines and Privacy Notice.

Result: the product and its key policies now ship in 11 languages from one source of truth.

A compliance program in six weeks

favorited · CIS Controls v8, cloud posture, access management

When IT security and compliance landed on my desk, there was no program to inherit. In six weeks I ran a gap analysis, wrote eight core policies, completed the first access review with an offboarding checklist, built a vendor inventory, and trained the whole company on security awareness. I also built a small internal tracker in Next.js to keep the work visible.

Result: 35 employees trained, and cloud-posture findings cut by about 50% after remediation.
